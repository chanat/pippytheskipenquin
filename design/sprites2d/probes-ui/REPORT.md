
## ภาพทดลอง "ทำให้โดดเด่น" (5 พ.ย. 2026, บ่าย) — `probes-ui/`
ผู้ใช้ดูสกรีนช็อตในเกม (`probes-ui/ref-current-hud.png`) แล้วบอกว่าดูเรียบ แบน เหมือนภาพสีน้ำเด็กวาด อยากได้ความ
นูน เงา มันวาว แบบ UI เกมมือถือดังๆ (ดาวทอง ริบบิ้น ป้ายคะแนน) → ทำ mock สกรีนช็อตทั้งจอ 3 ระดับความเข้ม
(Nano Banana Pro 2k, 2 เครดิต/ภาพ, รวม 6, ยอดคงเหลือ 341.6 → 335.6) โดยใช้สกรีนช็อตเดิมเป็น image_references
กำหนด layout และ element pip-v4 เป็นตัว Pip:
- `ui-probe-1-sticker` — สติกเกอร์เส้นหนา สีแบนจัด เงาทึบเยื้อง (เข้ากับ Pip v4 ที่สุด ทำเป็นสไปรต์/9-slice ง่ายสุด)
- `ui-probe-2-gloss` — มันวาว มีไล่สี มี bevel เงานุ่ม ตัวหนังสือนูน (ใกล้ตัวอย่างที่ผู้ใช้ให้มาที่สุด)
- `ui-probe-3-toy3d` — เรนเดอร์กึ่ง 3D พลาสติกเงา ไม้ขัดมัน ทองเมทัลลิก ประกาย (หรูสุด แต่ Pip แบนจะดูแปลกแยกกว่า)
สิ่งที่ทำให้จอจริงดูแบน (ไม่ใช่ที่ชีตสไปรต์ซึ่งมีเงา/ไฮไลต์อยู่แล้ว): HUD วาดด้วยโค้ด UGUI (`Hud.cs` BuildTopBar /
BuildProgress — หัวใจ path สีเดียวเส้น 2px, แผ่นไม้ลายทางสีเดียว, ชิปเหรียญสีเดียว, แถบ progress ขาวล้วน) ไม่มีเงาตก
