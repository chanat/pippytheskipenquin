## ทำใหม่ (5 จากที่อนุญาต 8)
- **s03** — รอบแรกได้แค่ 3 ท่า + หัวบีเวอร์สีเหลืองเกิน 4 หัว, แว่นปิดตา → รอบสอง: แว่นอยู่หน้าผากถูกแล้ว แต่ยังได้ 3 ท่า (ขาดเลี้ยวขวา) + หัวเกิน 4 หัว (สีขาว)
- **s05** — เนินหิมะปิดกับเนินมีหมีติดกัน ตัดแยกไม่ได้ → รอบสองแยกชัด
- **s07** — ออกมาพื้นขาวและมีเส้นขอบ → รอบสองพื้นดำ ไม่มีขอบ
- **b2** — มีแถบเบลอขวางด้านล่าง → รอบสองเป็นลายสม่ำเสมอ ต่อกันได้
- **t2** — มีหัวเพนกวินจางๆ 3 หัวลอยบนฟ้า → รอบสองยังมีอยู่ และภูเขากลายเป็นสีลูกกวาด → **เก็บรอบแรกเป็นตัวจริง** (t2-rej1 = รอบสอง)

## ปัญหาจากตัวลบพื้นหลัง
- s04: หิมะสีขาวบนยอดต้นสนทั้ง 4 ต้นถูกลบเป็นโปร่งใส (มีรูพื้นหลังโผล่)
- s01: ละอองหิมะตอนเลี้ยวซ้ายหายเกือบหมด เลี้ยวขวาเหลือแบบโปร่งแสง
- s02: กองหิมะใต้ท่านั่งมึนหัวหายเหลือแต่เส้นขอบ
- s06: ป้ายขาวบนซุ้มเส้นชัยโปร่งแสงบางส่วน, แสงเรืองรอบคริสตัลหาย
- s03, s05: เรียบร้อย
- ทุกไฟล์มี alpha จริง (พื้นหลังโปร่งใส 51–68% ของพิกเซล) แต่ตัววัตถุมี alpha = 254 ไม่ใช่ 255 (ทึบ 99.6%) — ใน Unity ไม่น่ามีผล แต่ถ้าต้องการทึบเต็มให้ clamp ตอน import

## 5 อย่างที่ควรดูก่อน
1. **t2** — ลบหัวเพนกวินจางๆ 3 หัวบนฟ้า (หรือ crop/ทำใหม่โดยไม่ใส่ภาพอ้างอิง)
2. **s03 Benny** — ขาดท่าเลี้ยวขวา (mirror ท่าเลี้ยว), ทิ้งแถวหัวล่าง
3. **s04 cutout** — ยอดหิมะต้นสนโปร่งใส ต้องเติมคืนหรือตัดพื้นเองจากชีตต้นฉบับ
4. **b3** — ขวาล่างมีขอบลาน+ต้นสนโผล่ (ควรเป็นลานว่าง) และต้องเช็กรอยต่อบน-ล่าง
5. **s02** — หัวกลมเกิน 1 ชิ้น, กองหิมะท่ามึนหายใน cutout

ข้อแนะนำรอบหน้า: ภาพอ้างอิงที่ส่งเป็น image_references ควรเป็นตัวเดี่ยว (ไม่มีแถวหัว) เพื่อไม่ให้ layout ถูกลอก

## v4 — Pippy redesign (5 Nov 2026, afternoon)
The user judged v3 Pippy too busy ("ตากลมๆ เล็กๆ สีขาว ทำให้เรียบง่าย"). Three probes (`probes-v4/`): A navy, B sky-blue, C classic black with small round white eyes — **C chosen**; registered as element `pip-v4` (`0239c242-a5ee-46e2-8685-47ec565ece2b`). Regenerated s01 (ski poses, now with a second "straight" frame for a two-frame ski-pump cycle; first try rejected because the two straight frames did not match), s02 (emotes) and s03 (Benny, same simplified style via image_references). The v3 character sheets moved to `sheets/v3/`; the v4 sheets took their file names so `SpriteImport` picks them up unchanged. 8 images, 14 credits (balance ≈ 343.6). Props, items, gates, VFX and backdrops stay v3.
